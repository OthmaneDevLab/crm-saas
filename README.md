## 🚀 Overview
A **CRM SaaS Platform** designed to manage leads, pipelines and customer relationships  
with a clean dashboard and scalable backend architecture.

---

## ✨ Features
- Lead Management  
- Sales Pipelines  
- Status Tracking (New / Contacted / Closed)  
- Role & Permission System  
- Dashboard Analytics  
- Secure Authentication  

---

## 🧠 Architecture
- Modular backend structure  
- RESTful APIs  
- Scalable database design  
- Clean separation of concerns
